# Batch C content plan — 370 → 435 topics

This plan was frozen before Set C1 implementation. It is based on the checkpoint-370 coverage audit, not only on the suggested-title list.

## Audit decisions

- Preserve the exact recommended level growth: A1 +10, A2 +17, B1 +22, B2 +16.
- Add 253 conversations: 20 topics × 3, 32 × 4, and 13 × 5.
- Prefer communication, public-place, event, fitness, advanced-work, travel-change, and safe emergency-language gaps.
- Do not add `joining-a-gym`, `booking-a-sports-court`, or `negotiating-project-scope`: semantic equivalents already exist. Use schedule cancellation, workout rescheduling, and resource negotiation instead.
- Every scenario has a distinct operational objective. Flexible requests, clarification, negotiation, apology, disagreement, and follow-up turns receive meaningful accepted phrasings.
- A1 conversations use 6 turns, A2/B1 use 8, and B2 uses 10. No exchange exists only to lengthen a lesson.
- The build audit found that the >500 kB chunk was metadata, not lesson turns: the generated manifest repeated all vocabulary and situation/goal text. The manifest now caps authored search tags at eight and keeps only discovery metadata. Post-audit largest chunk: 399.26 kB raw / 109.06 kB gzip; main bundle: about 80 KiB gzip; warning resolved.
